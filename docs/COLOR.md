# Color system: dye-derived, trust-first

The palette is not decorative. Every hue maps to something a buyer can see in a real Anatolian rug, which is the
whole message of the brand: _what you see is what it is._

| Token                       | Hex     | Comes from                                                 | Job on the site                                         |
| --------------------------- | ------- | ---------------------------------------------------------- | ------------------------------------------------------- |
| Ivory `--color-ivory`       | #F6F1E9 | undyed wool, the rug's natural ground                      | page background; the "honest, unfiltered" canvas        |
| Sand `--color-sand`         | #E9DFCF | camel hair, undyed dark wool                               | section rhythm, cards; warmth without color             |
| Madder `--color-madder`     | #9E2B25 | madder root (_Rubia tinctorum_), the classic Anatolian red | primary action only: Buy, Join, links                   |
| Indigo `--color-indigo`     | #23395B | indigo vat dye                                             | headings, footer, secondary buttons; authority and calm |
| Saffron `--color-saffron`   | #D9A441 | weld / saffron yellow                                      | badges and highlights, never body text                  |
| Olive `--color-olive`       | #6B7B4B | walnut husk + weld over-dye                                | "available" and success states                          |
| Charcoal `--color-charcoal` | #2B2B2B | undyed black-brown wool                                    | body text                                               |
| Stone `--color-stone`       | #6E6A64 | grey fleece                                                | secondary text (darkened on sand for AA)                |

## Color theory behind it

- **Split-complementary.** Madder red (hue ~4°) sits opposite indigo-blue (hue ~215°); saffron (hue ~40°) is the warm split. Red and blue are the two colors every Turkish rug buyer already associates with "real"; saffron keeps the pair from feeling corporate.
- **Warm ground, cool authority.** Ivory/sand are warm neutrals (like daylight on wool), so the indigo text reads cooler and more trustworthy by contrast, and the rug photography, which is mostly warm reds and golds, sits on the page instead of fighting it.
- **60 / 30 / 10.** Roughly 60% ivory and sand, 30% indigo (type, footer, secondary UI), 10% madder. Madder is reserved for the one thing we want a hand to move toward. Saffron is under 2%: badges, star ratings, the trade teaser button.
- **Low chroma, high value contrast.** Saturation stays moderate (madder is a brick red, not a candy red; indigo is a night blue, not electric). Contrast comes from lightness, which is what makes the pairs pass WCAG AA: madder on ivory 6.6:1, indigo on ivory 10.3:1, ivory on indigo 10.3:1, stone on ivory 4.8:1 (`tests/unit/contrast.test.ts` enforces every pair in `src/lib/tokens.ts`).
- **No black, no pure white.** Charcoal and ivory keep the page in the same "natural fiber" register as the products. Pure white is used only for form fields and cards on sand, where it reads as paper.

## Usage rules (also enforced in components)

1. One madder element per viewport where possible: the primary CTA. Links are madder too, but body links are short.
2. Indigo for anything that must feel considered: headings, prices, the Provenance Report card, the footer.
3. Saffron never carries text on ivory (3.4:1). It carries charcoal text on its own background (6.1:1).
4. Olive for status only; olive-dark (#4F5C36) when it is text at body size.
5. Sold rugs desaturate 30% and use charcoal badges; sold is a fact, not a warning, so no red.
6. Photography rules: daylight, no filters, white-balance card in frame. The palette is calibrated to true-to-color rug photos; heavily edited images will clash.
7. Error is #B3261E, a different red from madder on purpose, so a form error never looks like a call to action.
