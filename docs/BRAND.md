# Brand: Provenant Rugs

**Name:** Provenant Rugs · **Tagline:** Verified at the Loom · **Per-rug proof:** the Provenance Report

Chosen by Chris from the brand availability check (Sep 28, 2026), where it ranked #2 of 19 candidates:
`provenantrugs.com` appeared unregistered (Verisign RDAP; `provenant.com` is an EU digital-product-passport company),
`@provenantrugs` appeared free on Instagram (unverified, logged-out check), and the existing PROVENANT marks at USPTO
are in unrelated classes (9/42 software, 12 vehicles), with nothing in Class 27 (rugs) or 35 (retail).
"Provenant" means "having provenance": the name says the positioning in one word.

Known risks from the check: closeness to the generic word "provenance" (Jaipur Rugs sells a "Provenance" collection),
and some people will misread it as "Provenance". Lean into it: every rug gets a **Provenance Report**.

## Before committing (from the check)

1. Register `provenantrugs.com` and `@provenantrugs` the same day, plus `.co` if cheap.
2. USPTO free-form wordmark search for sound-alikes (PROVENANT / PROVENANCE); DC trade-name check (DLCP).
3. Trademark attorney clearance before filing in Classes 27 and 35 (about $350 per class; verify current fee).
   The availability check was a knock-out screen, not a clearance search.

## Where the name lives in code

`PUBLIC_BRAND_NAME`, `PUBLIC_DEALER_NAME`, `PUBLIC_SITE_URL`, and social URLs in `wrangler.toml` `[vars]` and the
Pages build environment; defaults in `src/lib/site.ts`. The certificate PDF header, manifest, and JSON-LD all read
from there. Changing the name is a config change, not a code change.
